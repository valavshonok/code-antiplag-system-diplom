Установить для тестирования
pip install pytest pybind11

Скачать и установить Cmake
https://cmake.org/download/?utm_source=chatgpt.com

Установить Visual Studio Build Tools
https://visualstudio.microsoft.com/visual-cpp-build-tools/?utm_source=chatgpt.com

Далее работаем в терминале Developer PowerShell for VS 2022

cl
Должно вывести что-то вроде:
Microsoft (R) C/C++ Optimizing Compiler
